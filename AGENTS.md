# AI Agent Rules

1. **Fokus Development, Hindari Check yang Memperlambat**:
   - Jangan jalankan `npm run check`, `npm run lint`, `npm run build`, `svelte-check`, atau command verifikasi berat lainnya secara otomatis selama proses development.
   - Fokus langsung pada implementasi fitur, perbaikan bug, dan menjalankan dev server (`npm run dev`) bila diperlukan.
   - Jalankan command check/build hanya jika user secara eksplisit memintanya.
